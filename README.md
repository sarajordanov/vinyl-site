# VINYL.

A full-stack vinyl record store, built from my own UI/UX design.

**Stack:** React, JavaScript, Node.js, Express, PostgreSQL, Git

## Run it locally

Start the server (port 4000):

```bash
cd server
npm install
npm run dev
```

Start the client (port 5173), in a second terminal:

```bash
cd client
npm install
npm run dev
```

Then open http://localhost:5173
